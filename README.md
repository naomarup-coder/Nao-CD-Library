# 118 CD Library

CDを「冊 → アーティスト名 / タイトル → 曲目 → 歌詞カード」の階層で管理する、スマートフォン対応の静的Webサイトです。

## ファイル構成

- `index.html`：ページの骨組み
- `styles.css`：色、配置、スマホ対応などの見た目
- `app.js`：CDデータ、一覧表示、登録・編集、検索、画像表示、QRコード、バックアップ

機能を変更するときは、まず `app.js` の先頭にある「主な編集場所」を確認してください。

## パソコンで確認する

1. このフォルダーをVisual Studio Codeで開きます。
2. `index.html` をブラウザで開きます。より安定して確認するにはVS Codeの「Live Server」拡張機能を使ってください。
3. CDの登録・編集、曲目の入力、歌詞カード画像の登録を試します。

## スマートフォンでQRコードから開く

スマートフォンで開けるようにするには、3ファイルをWeb上に公開する必要があります。ファイルをパソコンで開いただけでは、QRコードをスマホで読み取ってもアクセスできません。

### GitHub Pagesで公開する手順

1. GitHubにサインインし、新しいリポジトリを作成します（例：`118-cd-library`）。
2. `index.html`、`styles.css`、`app.js` の3ファイルをリポジトリ直下にアップロードします。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment** の **Deploy from a branch** を選び、`main` ブランチと `/(root)` を指定して保存します。
5. 数分後に表示される公開URL（例：`https://ユーザー名.github.io/118-cd-library/`）を開きます。
6. 公開URLをパソコンで開き、ページ右上の「ライブラリQR」を押してQRコードを表示・印刷します。
7. スマートフォンのカメラでQRコードを読み取り、サイトが開くことを確認します。

GitHub Pagesの画面名は変更されることがあります。公開URLが表示されるまではQRコードを印刷しないでください。

## データ保存について（重要）

この版は `localStorage` を使用しているため、登録したCDや画像は「そのブラウザ・その端末」に保存されます。パソコンで登録したデータが自動的にスマホへ同期されるわけではありません。スマホから公開サイトを開いたとき、初期データは見られますが、パソコン側で追加したデータや歌詞カード画像は別途同期機能を実装しない限り表示されません。

データを失わないように、ホーム画面の「バックアップ」からJSONファイルを定期的に保存してください。「復元」からJSONファイルを読み込めます。

複数端末で同じデータを共有したい場合は、次の段階でFirebaseやSupabaseなどのデータベースを接続する必要があります。また、歌詞カード画像の共有にもクラウドストレージが必要です。

## QRコードについて

QRコード画像の作成には外部のQRコード生成サービスを使用します。そのためQRコードを表示する際は、公開URLがそのサービスに送信されます。機密情報をURLに含めないでください。
